## 项目

| 文件夹 | 说明 | 功能 |
|--------|------|------|
| [PySandboxGame](./PySandboxGame/) | 第一代 — 2D 方块世界 | 方块放置/破坏、背包、箱子、多种方块 |
| [PySandboxGame2](./PySandboxGame2/) | 第二代 — 模块化重构 | 生物系统、武器、合成、熔炉、掉落物、音效 |

## 运行

```bash
pip install pygame
cd PySandboxGame    # 或 PySandboxGame2
python 程序文件.py   # 一代
python 启动程序.py   # 二代
```
